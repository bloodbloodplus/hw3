# Домашнее задание к работе 3

## Условие задачи

**Написать и отладить программу пересчёта давления из миллиметров ртутного столба (мм рт. ст.) в бары и паскали.**


---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало.**
2. Объявить переменные:
   - `mmHg` — давление в миллиметрах ртутного столба;
   - `pascal` — давление в паскалях;
   - `bar` — давление в барах.
3. **Ввести** значение давления в миллиметрах ртутного столба `mmHg`.
4. Выполнить перевод давления в паскали:

   **pascal = mmHg × 133.322**

5. Выполнить перевод давления из паскалей в бары:

   **bar = pascal / 100000.0**

6. **Вывести** значение давления в паскалях.
7. **Вывести** значение давления в барах.
8. **Конец.**
